# lib/melonloader-mono

MelonLoader **net35** build, used by the Mono flavour (Mono games run on the old .NET Framework-style runtime). Not included in the repo.

Source: the official MelonLoader release (https://github.com/LavaGang/MelonLoader/releases), or
`<game>/MelonLoader/net35/` of a Mono install. Use the version you play with.

Needed: `MelonLoader.dll`, `0Harmony.dll`
