# lib/mono

Game assemblies for the **Mono** branch. Not included in the repo: copy them from your own install.

Source: `<game>/Schedule I_Data/Managed/`

Needed to build the `mono` flavor of `persistent-pot-additives`:
`Assembly-CSharp.dll`, `ScheduleOne.Core.dll`, `FishNet.Runtime.dll`, `UnityEngine.dll`,
`UnityEngine.CoreModule.dll`
