# lib/il2cpp

Proxy assemblies for the **IL2CPP** (main) branch. Not included in the repo: generate them from your own install.

Source: `<game>/MelonLoader/Il2CppAssemblies/`, created the first time you launch the game with
MelonLoader installed (needs internet once).

Needed to build the `il2cpp` flavor of `persistent-pot-additives`:
`Assembly-CSharp.dll`, `Il2CppScheduleOne.Core.dll`, `Il2CppFishNet.Runtime.dll`, `Il2Cppmscorlib.dll`,
`UnityEngine.dll`, `UnityEngine.CoreModule.dll`
