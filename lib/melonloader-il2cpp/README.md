# lib/melonloader-il2cpp

MelonLoader **net6** build plus Il2CppInterop, used by the IL2CPP flavour (IL2CPP games host a modern .NET 6 runtime). Not included in the repo.

Source: `<game>/MelonLoader/net6/` of an IL2CPP install (or the official MelonLoader release).

Needed: `MelonLoader.dll`, `0Harmony.dll`, `Il2CppInterop.Runtime.dll`
